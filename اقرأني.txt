إعداد نشر مدرسة الشيخ محمد حسين الكاظمي على Railway

1) فك الضغط. داخل مستودع GitHub اضغط Add file → Upload files.
2) ارفع الملفات الثلاثة إلى جذر المستودع نفسه حيث يوجد index.html ومجلد project: Dockerfile و Caddyfile و .dockerignore.
3) اضغط Commit changes. لا ترفع مجلدًا إضافيًا حول الملفات ولا ملف ZIP نفسه.
4) في Railway: New Project → Deploy from GitHub repo → Mohammed-Hussein-Al-Kazemi-School → Deploy.
5) اترك Root Directory على / (الجذر). بعد نجاح البناء افتح الخدمة → Settings → Networking → Generate Domain.

الموقع الحالي تجربة محلية؛ Railway ينشر الواجهة فقط ولا يربط حسابات الطلاب والأساتذة بين الأجهزة.
