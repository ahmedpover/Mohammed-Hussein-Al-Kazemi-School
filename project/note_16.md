# مشغّل المحاضرات v0.10.9
- افتح محاضرة واضغط «فتح المشغّل الصوتي»، ثم زر التشغيل.
- يستمر الصوت أثناء التنقل بين صفحات الموقع لأن عنصر الصوت موجود خارج محتوى الصفحة المتغيّر.
- التقديم والترجيع 5 ثوانٍ، تغيير السرعة، حفظ الموضع محلياً في المتصفح كل 5 ثوانٍ وعند الإيقاف.
- Media Session API يتيح ظهور عناصر التحكم بالصوت في إشعار الوسائط على Android والمتصفحات الداعمة عند استمرار التشغيل بالخلفية. ليس إشعار Web Push؛ لا يحتاج إذن الإشعارات.
- التشغيل بالخلفية ليس مضموناً على جميع الأجهزة: قد يوقف نظام التشغيل الصوت عند إغلاق المتصفح قسرياً أو توفير البطارية أو نفاد الذاكرة. على iPhone تختلف عناصر التحكم بحسب Safari وإصدار iOS. لا يمكن ضمان التشغيل بعد إغلاق التطبيق قسرياً.
- يجب اختبار التشغيل والتحكم من شاشة القفل على هاتف حقيقي قبل النشر العام.
