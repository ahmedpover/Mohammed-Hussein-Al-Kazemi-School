# تثبيت تطبيق المدرسة على الهاتف

بعد رفع هذه النسخة إلى GitHub واكتمال نشر Railway، افتح رابط المدرسة الرسمي من هاتفك:

`https://mohammed-hussein-al-kazemi-school-production.up.railway.app/`

## iPhone

افتح الرابط في **Safari**، اضغط زر المشاركة، ثم **إضافة إلى الشاشة الرئيسية** (Add to Home Screen)، وبعدها **إضافة**. ستظهر أيقونة المدرسة بين التطبيقات.

## Android

افتح الرابط في **Chrome**، اضغط قائمة النقاط الثلاث، ثم **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**، ووافق على الإضافة.

التطبيق يحتاج الإنترنت لتسجيل الدخول والوصول للمحاضرات والقنوات. إذا انقطع الإنترنت تظهر صفحة واضحة تطلب إعادة المحاولة. التحديثات الجديدة تظهر للمستخدم عند فتح التطبيق مع توفر الإنترنت؛ لا يحتاج تنزيل ملف APK.
