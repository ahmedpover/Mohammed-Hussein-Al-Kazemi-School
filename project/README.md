# مدرسة الشيخ محمد حسين الكاظمي — معاينة v0.5

واجهة عربية متجاوبة بباليتة بيجية حجرية وخط عربي رسمي، مستوحاة من عمارة المدرسة. هذه نسخة معاينة قابلة للتشغيل، وليست منصة للطلاب الحقيقيين بعد.

## افتح المعاينة مباشرة

بعد فك الضغط، اضغط ملف `index.html` الموجود **بجوار مجلد `project`**. هذا الملف مستقل وفيه صورة المدرسة، ويفتح مباشرة دون تثبيت شيء.

ملف `project/index.html` هو مدخل مشروع التطوير، وفتحه مباشرة من الملفات يعرض شاشة بيضاء لأن المتصفح يحتاج خادم تطوير له. لا تستخدمه للمعاينة المباشرة.

## تشغيل مشروع التطوير

يتطلب Node.js 20.19 أو أحدث.

```bash
npm install
npm run dev
```

افتح الرابط المحلي الذي يظهر في الطرفية. لإنشاء ملفات النشر: `npm run build`؛ المخرجات في `dist/`.

لتجديد ملف المعاينة بعد تعديل الكود: من داخل مجلد `project` شغّل `npm run preview:offline`.

## الموجود الآن

- صفحة حساب لإنشاء حساب طالب أو أستاذ وتسجيل الدخول والخروج على الجهاز نفسه. كلمات المرور مخزنة كقيمة مشتقة بملح، وليس كنص صريح، لكن هذه ليست مصادقة آمنة لخدمة عامة.
- يكتب الأستاذ اسم المادة واسم الكتاب بنفسه عند إضافة المحاضرة أو إنشاء القناة، وتظهر المواد والكتب التي أضافها في واجهة الطالب. لا توجد قائمة مواد مفروضة ولا محاضرات نموذجية مسبقة.
- البحث عن المحاضرات بالعنوان أو المادة أو الكتاب.
- إضافة محاضرة وتعديلها وحذفها، وإرفاق صوت أو PDF من جهاز الأستاذ.
- تشغيل الملف الصوتي داخل المتصفح، استكماله من الموضع المحفوظ، وفتح PDF أو تنزيله.
- ملاحظات ومفضلة وسجل زيارة محفوظة محليًا في نفس المتصفح.
- حفظ بيانات المحاضرات والإشعارات محليًا، والملفات في تخزين المتصفح إذا أتاحه.
- قنوات للمواد: ينشئ الأستاذ قناة باسم مستخدم فريد واسم مادة وكتاب، وينشر تعليمات وصورًا، ويعدّل محتواها بحذف المنشورات أو القناة. إدارة القناة مرتبطة بحساب منشئها في هذه المعاينة.
- يبحث الطالب عن قناة المادة باسم مستخدمها، وينضم إليها ليقرأ منشوراتها، ويستطيع مغادرتها. جرّب إنشاء قناة من واجهة الأستاذ ثم بدّل إلى واجهة الطالب.
- إشعارات داخل المعاينة، واجهة ليلية، وتصميم للموبايل والكمبيوتر.

## قبل استخدام المنصة فعليًا

الحسابات هنا تجريبية داخل المتصفح وليست حسابات موثقة من المدرسة. يمكن لأي شخص إنشاء حساب أستاذ على جهازه، ولا توجد صلاحيات محمية بخادم. القنوات والانضمام والمنشورات محلية على هذا المتصفح فقط؛ لا تظهر القناة على جهاز طالب آخر. الصور مخزنة في متصفح الجهاز إذا أتاح التخزين، وقد يمسحها المتصفح أو يمنع حفظها عند فتح الملف مباشرة. الإشعارات ليست Push. لا ترفع بيانات طلاب حقيقية أو تسجيلات خاصة هنا.

المرحلة التالية هي ربط حسابات الطلاب وتفعيل الأكواد لأول مرة، ودخول الأستاذ بالبريد، وقاعدة بيانات Firebase مع قواعد وصول على الخادم، وتخزين خاص للتسجيلات وPDF، وإدارة الطلاب واستيراد CSV/Excel، ثم إشعارات الهاتف وإحصائيات التشغيل. لا يكفي إخفاء الأزرار في الواجهة لحماية المحتوى.

## إعداد النشر مستقبلًا

الخيار المتفق عليه: Cloudflare Pages للواجهة وFirebase للحسابات والبيانات. إعداد البناء في Pages: `npm run build` ومجلد الناتج `dist`. لا تجعل الموقع عامًا بمحتوى خاص قبل إكمال الربط والصلاحيات.

الصورة المستخدمة في الواجهة هي الصورة التي قدّمها صاحب المشروع للمدرسة.
