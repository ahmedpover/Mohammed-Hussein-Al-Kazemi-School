# مدرسة الشيخ محمد حسين الكاظمي — v0.9

تطبيق عربي للمدرسة مبني بواجهة React وخادم Node.js وقاعدة PostgreSQL على Railway.

- المدير يرى الأساتذة والطلاب والقنوات والمحاضرات. يعتمد بريد الأستاذ ومواده ويحدد رمز دعوته أو يطلب رمزاً آلياً.
- سجل الطلاب يعرض حسابات الطلاب المسجّلين، رقم الدورة الذي يدخله المدير، والقنوات والمواد التي انضم إليها الطالب. الانضمام لا يثبت إكمال دراسة المادة.
- المدير يرسل إشعاراً خاصاً إلى حساب الطالب. الطالب يراه في صفحة «الإشعارات» داخل الموقع، مع عدد الإشعارات غير المقروءة. لا يرسل هذا الإصدار بريدًا إلكترونيًا أو إشعار هاتف.
- الأستاذ يختار كلمة مروره بنفسه عند التسجيل ببريده ورمز الدعوة، ثم ينشر قنوات ومنشورات ومحاضرات لمواده المعتمدة.

انشر النسخة برفع مجلد `project/` و`Dockerfile` إلى مستودع المدرسة بالمسارات نفسها؛ قاعدة البيانات الحالية لا تحتاج إعادة إنشاء. التعليمات الأساسية في [RAILWAY_POSTGRES_SETUP_AR.md](RAILWAY_POSTGRES_SETUP_AR.md).

للعمل المحلي: `npm ci`، ثم `npm run build` و`npm start` مع `DATABASE_URL`. المرفقات مخزنة في PostgreSQL، ويجب توفير نسخ احتياطية منها.
