# مدرسة الشيخ محمد حسين الكاظمي — v0.8

تطبيق المدرسة: React، خادم Node.js وPostgreSQL على Railway. الحسابات والجلسات والمواد والقنوات والمنشورات والمرفقات تُحفظ في PostgreSQL. المدير يعيّن بريد الأستاذ ومواده ورمز دعوة خاص به.

خطوات النشر وحساب المدير الأول: [RAILWAY_POSTGRES_SETUP_AR.md](RAILWAY_POSTGRES_SETUP_AR.md).

للتطوير: `npm ci` ثم `npm run build` و`npm start` مع `DATABASE_URL` لقاعدة PostgreSQL. ملف المعاينة المنفصل في جذر الحزمة يمثل الواجهة المحلية القديمة.

الصور والصوت وPDF مخزنة في PostgreSQL؛ حد الصور 5 ميغابايت وحد مرفق المحاضرة 25 ميغابايت. يلزم توفير نسخ احتياطية من قاعدة البيانات. البيانات المحلية القديمة لا تنتقل تلقائياً.
