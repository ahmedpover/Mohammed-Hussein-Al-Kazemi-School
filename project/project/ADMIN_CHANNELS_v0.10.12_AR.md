# تحديث v0.10.12 — إنشاء القنوات نيابة عن الأساتذة

- يسجل المدير الدخول، ثم يفتح **القنوات ← إنشاء قناة**.
- يختار الأستاذ **المسجل والمفعّل** من القائمة، ثم يختار إحدى مواده المعتمدة ويكتب معلومات القناة.
- تُحفظ القناة باسم الأستاذ وبمعرّف حسابه، ويستطيع نشر المنشورات والمحاضرات فيها من حسابه، حتى لو أنشأها المدير.
- يبقى المدير قادرًا على إدارة القنوات.
- لا يمكن اختيار أستاذ لديه دعوة فقط ولم يسجل حسابه؛ يجب تسجيل الحساب أولًا.
- هذا التحديث لا يغيّر قاعدة البيانات ولا يحتاج متغيرات Railway جديدة.

## النشر
فك ملف ZIP وارفع **محتويات مجلد project** إلى مجلد `project` في مستودع GitHub مع استبدال الملفات المتطابقة، ثم Commit changes. **لا ترفع مجلد project آخر داخل project**. تأكد أن ملفات `project/src` و`project/server` حُدثت فعليًا.

## الفحص
فحص صياغة JavaScript للخادم ناجح. لم يكتمل بناء الواجهة محليًا لعدم تثبيت الاعتماديات، ويجب إجراء اختبار على Railway بحساب مدير وأستاذ تجريبي قبل الاعتماد.
