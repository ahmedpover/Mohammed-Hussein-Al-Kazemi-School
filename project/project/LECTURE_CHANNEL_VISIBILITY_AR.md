# تحديث ربط المحاضرات بالقنوات

## طريقة العمل بعد التحديث

1. ينشئ الأستاذ قناة مستقلة لكل مجموعة أو دورة، مثل «دورة 14» و«دورة 13».
2. عند إضافة محاضرة، يختار الأستاذ القناة المستهدفة من حقل «القناة التي ستُنشر فيها».
3. لا تظهر المحاضرة للطالب إلا إذا كان منضمًّا إلى القناة المحددة. وتظهر محاضرات القناة داخل صفحة القناة نفسها، كما تظهر في قائمة المحاضرات العامة للطالب المنضم إلى تلك القنوات فقط.
4. يتحقق الخادم من عضوية الطالب قبل إرسال ملف الصوت أو PDF، لذلك لا يكفي الحصول على رابط الملف للوصول إليه من حساب غير منضم.

## قاعدة البيانات والمحاضرات القديمة

عند تشغيل الخادم، يضيف التحديث عمود `channel_id` وفهرسًا له باستخدام `ALTER TABLE` و`CREATE INDEX IF NOT EXISTS`. لا يحذف هذا التعديل الحسابات أو القنوات أو المحاضرات أو ملفاتها.

المحاضرات التي كانت موجودة قبل التحديث ستبقى محفوظة في حساب الأستاذ، لكنها ستكون غير مرتبطة بقناة، ولذلك لن تظهر للطلاب تلقائيًا. لعرض محاضرة قديمة، يفتح الأستاذ خيار «تعديل» ويختار القناة الصحيحة ثم يحفظ. لم تُربط المحاضرات القديمة تلقائيًا لأن وجود قناتين للمادة والكتاب نفسيهما لا يكفي لتحديد الدورة الصحيحة بأمان.

## النشر

ارفع ملفات المشروع المحدّثة إلى المستودع ثم أعد نشر الخدمة كالمعتاد. لا تحتاج إلى حذف قاعدة البيانات أو إنشاء قاعدة جديدة؛ سيُنفَّذ تعديل المخطط عند بدء الخادم.
