# تحسين تجربة الهاتف — v0.10.5

- إضافة شريط تنقل سفلي للصفحات الأكثر استخدامًا حسب نوع الحساب.
- إبقاء زر القائمة العلوية للوصول إلى بقية الصفحات وإعدادات المظهر وتسجيل الخروج.
- إظهار مؤشر للإشعارات غير المقروءة لدى الطلاب.
- تحسين المساحة الآمنة أسفل الشاشة على الهواتف ذات شريط النظام.
- تحسين تجاوب العناوين والنماذج وحقول رفع الملفات والحوار مع الشاشات الصغيرة.
- لا توجد تغييرات في قاعدة البيانات أو واجهات API.

## اختبار مطلوب بعد النشر
افتح الموقع من هاتف طالب وأستاذ ومدير، واختبر القائمة والتنقل والنماذج، خصوصًا على شاشات 320–390 بكسل.

> لم ينجح اختبار البناء المحلي لأن نسخة المشروع المرفوعة تحتوي على مجلد node_modules غير مكتمل ولا يحتوي على vite. نفّذ npm ci ثم npm run build في بيئة تتوفر فيها الاعتماديات.
