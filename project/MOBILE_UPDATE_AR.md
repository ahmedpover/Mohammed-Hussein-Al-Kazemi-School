تحديث واجهة الهاتف 0.10.1

أُصلح خروج زر البحث بمعرّف القناة من إطار الاستمارة.
على الهاتف يظهر حقل المعرّف ثم زر البحث تحته بعرض الاستمارة.
حُسنت حدود عناصر القنوات، البطاقات والاستمارات والنوافذ مع النصوص الطويلة.

الفحوص المنجزة:
- نجاح بناء نسخة الإنتاج.
- نجاح تجهيز واجهة القنوات بأدوار الطالب والأستاذ والإدارة وبمحتوى طويل.
- نجاح التجهيز الأولي للتسجيل، الطلاب، الإشعارات وقائمة الهاتف.
- نجاح تحليل ملفات CSS وفحص صياغة ملف الخادم.
- نجاح تقديم الصفحة وملفات الواجهة عبر خادم المعاينة المحلي.

حدود التحقق:
تعذر تشغيل متصفح لفحص القياسات والمظهر بصريًا في هذه البيئة.
هذه الفحوص لا تؤكد عمل تسجيل الدخول وعمليات البيانات مع قاعدة Railway الفعلية.

التحديث:
فك الضغط وارفع الملفات إلى GitHub بنفس مواقع الملفات السابقة.
انتظر اكتمال نشر Railway ثم حدّث الصفحة.
